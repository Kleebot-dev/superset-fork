## Flow Meter Chart

The Flow Meter chart displays one aggregate metric as a digital meter mounted
on a pipeline. Use it for KPI values such as water flow, gas flow, volume, or
throughput.

### Configure the chart

1. Select **Flow Meter** from the **KPI** chart category.
2. Choose the aggregate **Metric** to display.
3. In **Chart Options**, optionally set a **Unit**, such as `L/min` or `m³/h`.
4. Select a **Number format** or enter a custom D3 number format.

The chart displays the raw aggregate metric. It does not convert the value to a
percentage or restrict it to a minimum or maximum. The unit is display text and
does not transform the metric.
